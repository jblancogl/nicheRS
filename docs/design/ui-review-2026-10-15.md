# UI review — 2026-10-15 (implemented interface)

Method: headless Chromium (Playwright) against the release binary, viewport 1440×900 and 390×844,
synthetic demo and real runs (Lacerta bilineata / Brittany). Screens checked against
`laws-of-simplicity-audit.md`, `ux-specification.md` and `accessibility.md`. Automated smoke test:
`scripts/ui_smoke.py`.

## Findings and actions

| # | Screen | Finding | Law(s) | Action |
|---|---|---|---|---|
| 1 | Workspace (empty) | Map-first layout, single primary action ("Continue"), demo entry clearly labelled synthetic. | Reduce, The One, Trust | none |
| 2 | Setup — steps | Primary button labels state the consequence ("Use these 3", "Launch model run"); progress shows 6 named steps; context chip (species · area · model) always visible. | Organize, Context | none |
| 3 | Setup — data review (demo) | Synthetic demo region included the Mediterranean, so "occurrences" appeared at sea — ecologically absurd even for synthetic data and undermines trust. | Trust, Failure | Demo region moved inland (43.8–45.8 °N) in server and UI. |
| 4 | Results — desktop | Legend says "Relative habitat suitability (cloglog, 0–1) — not a probability of presence"; evidence level with ✓/✗ reasons; warnings first; extrapolation hatch on by default; occurrences distinguished by shape and colour. | Trust, Failure, Differences | none |
| 5 | Results — tiles | Verified that map colours match API values (tile pixel vs `/sample`, ±0.01 at z6–z9). | Trust | added to review checklist |
| 6 | Results — binary layer | Server colour (#35b779) differed from legend swatch (#21918c). | Trust | Server colour aligned to legend. |
| 7 | Results — mobile | Layer panel open by default covered most of the map; fit-to-bounds ignored the bottom sheet so the result was partly hidden. | The One, Context | Legend collapsed by default below 768 px; fitBounds pads by the sheet height. |
| 9 | Results | axe-core (WCAG 2.0/2.1/2.2 A+AA): 1 violation, target size of the two overlay checkboxes (16 px, 22 px apart). | Accessibility | Rows given ≥ 24 px height; re-audit: 0 violations on `/`, `/jobs`, results, light and dark. |
| 8 | All | CSP violation report: Zod 4 probes `new Function` at load. Harmless (blocked) but noisy and hides real CSP problems. | Trust (operational) | `public/zod-config.js` sets Zod `jitless` before the bundle; CSP unchanged (no `unsafe-eval`). |
